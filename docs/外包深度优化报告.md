## 二、架构合理性（修复 12 项）

**系统性短板：同步阻塞混入 async 路由**——单个慢请求即可冻结整个面板（与项目自己"绝不阻塞事件循环"的原则相悖）：

- `panel_routes` 9 处：体检探测、crontab 读写、**pip install 重装守护（可达数分钟）**、改时区、切监听、日志清理、prefs 自检写入 → 全部 `asyncio.to_thread`
- `file_routes` 8 处：读/写/建目录/移动/复制/删除/上传 → 大目录 copytree/rmtree 不再卡死终端 WS
- `process_routes`：全进程表两轮扫描 + net_connections → 下线程池
- `log_routes`：大日志读盘 → 下线程池

**配置热加载 mtime 秒级竞态（P0）**：PRoot/容器文件系统 mtime 只有秒级精度，`--disable-internal`/`--revoke-agent-token` 与面板加载落同一秒时**模式降级/令牌吊销不生效**（公网端继续放行终端）。改为 `(st_mtime_ns, st_size, st_ino)` 指纹判定。冒烟 #9 验证热加载立即生效。

**封装与一致性**：
- `boot.trim_logs` 不再摸 `AppLog._buffer` 私有属性（新增 `clear_memory()`）
- `metrics.basic_info` 的 `socket.getfqdn()`（同步反向 DNS，坏 DNS 挂数秒）加进程级缓存；`open()` 句柄改 `with`
- `main.local_addresses` socket 异常路径不再泄漏 fd
- 配置导入的 `pending_restart` 与提示语统一判定（原两处逻辑矛盾）
- `agent_routes` 引用 `terminal_routes._pick_shell` 私有符号（遗留，见文末）

## 三、核心功能与功能设计（修复 20 项）

### 致命（P0）
1. **tar 解压符号链接逃逸**（`file_routes._extract`）：「link -> /etc」+「link/shadow」两段式恶意包可写出目标目录。3.12+ 分支靠官方 data 过滤器 + **FilterError 转 400 并清场**（原来是 500 炸掉半解压现场）；旧版分支直接不还原链接，彻底断掉该路径。冒烟 #15/#16 验证。
2. **配置热加载失灵**（见架构节）。

### 重要（P1）
3. **`dirsize` 条件写反**：空子目录必 500（IndexError）、非空恒 null。改为 du 自身行 = 目录总占用。冒烟 #5/#6。
4. **`/api/files/read` 的 `max_bytes` 客户端可控**：传 `999999999999` 可把多 GB 文件读进内存 OOM。服务端钳制到 2MB。冒烟 #10。
5. **apps.json 解析失败静默置空**：一次瞬时读失败 → 运行中托管应用全部变孤儿（Supervisor 丢弃 runtime 记账）。改为保留上一份注册表。
6. **日志白名单自检有洞**：`/etc/ssh`、`/root/.ssh`、面板配置目录都能进白名单 → 公网只读用户读私钥/密码哈希。改为「与敏感目录存在包含关系即拒」+ 隐藏目录全拒。
7. **终端 WebSocket 清理只 TERM shell 本身**：孙进程泄漏。改 `killpg` 收整个进程组。

### 一般（P2）与边界
- `mount`/`umount` 参数注入：加 `--` 分隔（`path="-a"` 不再变成 `umount -a`）
- `/setup` 抢注竞态：`set_password(only_if_uninitialized=True)` 原子化 + 失败计数（冒烟 #4）
- 改密码无限暴力猜：复用登录失败锁定
- TLS 反代下 Cookie 无 `Secure`：trust_proxy 时认 `X-Forwarded-Proto`
- `/api/auth/status` 副作用与信息泄露：只读查询不续期、`active_sessions` 仅登录后返回（冒烟 #2）
- **进程详情泄露 environ（含 DATABASE_URL/API key）**：公网模式不再返回（冒烟 #7）
- 进程 signal/nice 的 PID 防护统一（拦 0/1 与面板自身/守护 PID）
- 日志接口 TOCTOU：`read` 后按 `/proc/self/fd/N` 复核真实落点；`tail` 前后 stat 比对 dev/ino
- 文件乐观锁 `expected_mtime` 改纳秒（同秒内外部修改现在能测出，冒烟 #11-13）
- `exec` 的 timeout 校验链式化（NaN 不再溜过去）、命令限长 64KB、审计截断
- 服务单元名拒绝 `-` 开头（防被当 systemctl 选项）
- `panel-status` 任务端口改为现场探测（不再硬编码 8787）

## 四、使用流畅度（修复 18 项）

### 致命（P0）
1. **`api.put()` 根本不存在**：「保存快捷设置」「编辑常驻应用」一调用就 `TypeError`，**功能完全不可用**。已补齐（冒烟 #1）。
2. **视图切换竞态**：快速切标签时慢请求的旧视图整块盖到新视图上；cleanup 归属错乱导致定时器泄漏。治理方案：
   - 视图代际 token（`viewSeq`）：过期渲染的 cleanup 立即回收（冒烟 #3b）
   - **slot 隔离容器**（`display: contents`）：每次导航新建槽位，旧视图迟到的异步写入落在脱离文档的旧槽里，盖不掉新视图（冒烟 #3），且顺带根治监听器跨视图残留
3. **文件管理 `load()` 乱序回写 `cwd`**：连点面包屑会「跳回上一个目录」。请求序号治理（进程/服务视图同修）。

### 重要（P1）
4. **轮询风暴**：8 个 `setInterval` 页面切后台仍全速打接口。统一 `every()` 可见性调度（隐藏时空转），覆盖 live 指标/概览/性能/日志/进程/端口/apps/重启探测（冒烟 #8）。
5. **断网完全无感知**：连续失败弹出「连接中断」横幅，恢复自动消失。
6. **fetch 无超时**：后端挂死=界面永久卡「加载中」。AbortController 兜底（默认 120s、轮询 8s、上传 600s，可按调用点覆盖）（冒烟 #7）。
7. **终端 WS 重连刷屏**：固定 1.5s 重连 + 每次红字 → 指数退避（1.5s→30s 封顶）+ 只在首次断开写终端提示、之后靠状态栏。
8. **settings `busy` 防重入是死代码**：`runBootAction`/`runPanelAction` 真正置位 + try/finally，重启面板/重装守护/切监听不能连点。
9. **编辑器保存连点**：保存期间按钮禁用 +「保存中…」；409 覆盖保存走新流程不自锁。

### 一般（P2）
- 日志过滤加 200ms 防抖 + 渲染上限 3000 行（2000 行逐字符重绘掉帧）
- 服务确认框英文 action（「执行 restart」）→ 中文映射；操作后 700ms 刷新定时器纳入 cleanup
- 进程表 PID 表头死交互 → 接上排序
- 弹窗无 ESC/无无障碍属性 → ESC 关闭（**对话框 ESC=取消并 resolve，Promise 不悬挂**，冒烟 #4/5/6）、`role="dialog"`、toast `role=alert/status`
- 启动串行三连请求 → status 复用 + capabilities 并行
- 终端栏硬编码「root 权限」徽章 → 按实际用户渲染
- 大文件编辑软提示（>512KB 提示下载本地编辑）

## 五、验证体系（新增）

原项目只有 pytest（59 用例）。本轮新增两套**动态冒烟**，专验优化是否真生效（而非只看测试全绿）：

1. `scripts/smoke_optimizations.py`（后端 17 项）：起真服务走 HTTP，验 setup 抢注、dirsize、environ 隔离、max_bytes 钳制、模式热加载、纳秒乐观锁、tar 逃逸、命令限长等
2. `.tools/frontend-test/smoke_frontend.js`（前端 9 项）：vm + 自制 DOM 桩加载 app.js，验 api.put、视图竞态隔离、cleanup 回收、ESC 语义、超时 AbortController、可见性轮询

**检查-返工记录**（三轮）：
- 第 1 轮：冒烟发现 tar 逃逸场景返回 500（3.12 FilterError 未捕获）→ 返工：转 400 + 清场 + 测试契约更新
- 第 2 轮：全量测试发现 `test_extract_zip_and_tar` 断言仍容忍旧 500 行为 → 返工：对齐新契约（200/400）
- 第 3 轮（独立复核）：重新 clone 原版做全量 diff，逐个审计全部 40 个改动 hunk → 发现 1 处遗漏：日志视图 `filterTimer` 防抖未纳入 cleanup（切走视图后 pending 的 paint 对空 DOM 报 TypeError）→ 已返工补齐。其余 hunk 全部审对（含 busy 锁交接无自锁、save 递归覆盖保存无自锁、slot 化不影响 terminal flex 布局、CSS 无直接子选择器、prefs 扁平 key 判定正确、`active_sessions` 字段前端零依赖等边界）。
- 终态：JS 语法 ✓ / Python 导入 ✓ / pytest 59 ✓ / 后端冒烟 17/17 ✓ / 前端冒烟 9/9 ✓

## 六、遗留改进建议（未修，按优先级）

### 值得做的（P2 剩余）
1. **审计分散三处不落盘**（apps/terminal/panel 各一个内存 deque，重启即丢）→ 建议统一审计模块 + append-only 落盘
2. **CLI/Web 双进程记账不一致**：CLI 拉起的托管应用不进 supervisor 记账，Web 显示"未运行"但实际在跑（`manage.py` 只有命令行模糊匹配兜底）→ 建议统一 pid 登记文件
3. **会话/Agent 令牌走 `?token=` 查询参数**（进反代日志/浏览器历史）→ 建议 WebSocket 改一次性短票或首条消息认证
4. 打包下载跟随符号链接、`/api/files/fetch` 的 SSRF 面（内网模式本就等价 root shell，风险可控）
5. 前端列表渲染增量优化（apps 页 3s 整页重绘、进程表 4s 整块重写、大目录文件列表无虚拟化）——高频使用体验值得投入
6. 移动端行内操作收进「⋯」菜单；`--muted` 小字对比度提亮

### 设计权衡说明（不是缺陷）
- **`/api/agent/info` 回显明文 Agent 令牌**：保留。调用前提是「已登录管理员 + 内网模式」（等价 root shell），而「复制令牌到 Agent 配置」是该页核心用途，默认掩码 + 显式显示。若要再收紧，可改为「令牌只在生成时返回一次 + info 仅回掩码」。
- **prefs 配置被改坏时静默回落默认**：方向安全（security.* 回安全默认），建议加 degraded 标记让用户感知。
- **tar 旧版分支（Python <3.12）不还原符号链接**：保守换安全，3.12+ 走官方 data 过滤器保留链接。

### 洁癖级（P3）
- 错误码全局统一（400/404/500 语义约定）
- 前端重复代码合并（电源操作两处、overview/performance 的 loadProcs）
- `confirmDialog` 的 message 默认转义、图片预览加载态、状态持久化策略统一
- 仓库根目录有个名为 `⚠️` 的杂散空文件，建议删除
